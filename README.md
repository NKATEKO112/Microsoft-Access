Database Portfolio: Microsoft Access Projects 🗄️

📖 Overview

Welcome to my Database Portfolio! This repository serves as a comprehensive collection of my Microsoft Access database projects.

Each file in this repository represents a different activity or project that demonstrates my ability to design, build, and manage relational databases from the ground up. Across all these activities, I have applied core database principles to create functional user interfaces, enforce data integrity, and extract meaningful insights from data. While the themes and data of each project vary, the foundational database skills applied remain consistent.

🛠️ Core Skills Demonstrated

Across all the projects in this repository, the following technical skills are consistently applied:

Table Design: Setting field properties, appropriate data types, primary keys, and captioning.

Data Validation: Setting validation rules for date ranges, input masks, and custom error messages.

Lookup & Multi-valued Fields: Creating dropdown lists and allowing multiple selections.

Queries: Using complex criteria (AND/OR), calculated fields, and aggregate functions (Group By, Count, Min, Max, Sum).

Forms: Applying conditional formatting, setting display properties, and creating user-friendly data entry points.

Reports: Grouping data, adding calculated controls, and designing professional print layouts.
